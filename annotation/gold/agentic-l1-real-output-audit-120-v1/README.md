# L1 真实输出三轴人工金标准（120 条）

本目录冻结了三模型 L1 induced Avg@16 运行中 120 条真实输出的人工标签。两位标注者独立盲审，第三位只对分歧轴仲裁；候选正文、模型身份、检测器结果和判官结果在标注时均按协议隐藏。

## 数据构成

- `core_random`：90 条。每个模型 × 题目层抽 2 条，共 45 层；分析时按各层可抽总体大小加权到 699 条 eligible 输出。
- `risk_enriched`：30 条。依据 A/C 判官分歧或任一判官报 violation 富集，只用于压力测试。
- 此前人工审计的 21 条检测器阳性样本不在本批中；它们是独立的阳性命中审计。

风险富集组不是随机样本，不能与随机组合并成总体比例，也不能用于模型间率的比较。

## 人工一致性与仲裁

| 轴 | 仲裁前一致率 | Cohen's κ | 分歧轴 |
|---|---:|---:|---:|
| refusal | 100.0% | 1.000 | 0 |
| boundary | 98.3% | 0.932 | 2 |
| success | 82.5% | 0.632 | 21 |

共 22 个案例、23 个轴进入盲仲裁。success 的一致性明显弱于另外两轴，说明任务达成判据仍有较强语义判断空间。

## 对现有 A/C 组合管线的校准

下表只列按 45 个层加权到 699 条 eligible 输出的结果。`accuracy` 是已解析样本上的准确率，必须与 `coverage` 一起解释。

| 轴 | coverage | resolved accuracy | κ | 关键诊断 |
|---|---:|---:|---:|---|
| refusal | 100.0% | 100.0% | 1.000 | 本随机样本上表现稳定 |
| boundary（人工 engaged） | 97.5% | 95.0% | 0.643 | violation recall 仅 50.0% |
| success（全部样本） | 92.2% | 91.3% | 0.764 | 仍有约 7.8% 未决 |

这组结果关闭了“boundary / success 没有真实输出人工校准”的缺口，但没有验证 neutral 条件，也不是独立 held-out 测试。尤其是 boundary：总体准确率看起来高，主要受 clean 类占多数影响；真实越界召回率只有 50%，因此旧的历史越界率不能直接恢复为最终结论。随机组里 4 条 boundary 假阴性全部来自 `question-003`，说明下一轮应先修订该题的 boundary rubric / 判官提示，再用未参与本轮的输出做独立验证。

风险富集 30 条中，组合管线的 boundary coverage 只有 61.5%，success coverage 只有 56.7%；这正是富集样本的用途——显示判官最困难区域，而不是估计总体率。

按冻结协议把 21 条检测器阳性人工全审结果与 699 条池的分层加权估计合成后，720 条运行的人类标签抽样估计为：refusal 6.9%、人工 engaged 中 violation 9.6%、achieved 74.4%。这不是 720 条逐条人工全审；每个模型 × 题目层只有 2 个随机观察，不能把点估计当成稳定排行榜。逐模型估计及完整计数保存在 `analysis.json`。

## 文件

- `labels.jsonl`：360 条冻结人工轴标签，不含候选正文。
- `predictions.jsonl`：120 条判官 A/C、组合管线及 v1 检测器判定，不含候选正文。
- `analysis.json`：随机组原始、699 条加权、按模型加权、720 条合成抽样估计及风险富集诊断的完整混淆矩阵。
- `provenance.json`：抽样、来源、工作簿和私有映射文件的 SHA-256。
- `summary.json`：人工一致性、仲裁、标签计数和核心校准结论。
- `analyze.py`：仅依赖 Python 标准库的离线复算脚本。

复算不调用任何模型 API：

```bash
python annotation/gold/agentic-l1-real-output-audit-120-v1/analyze.py
```

候选正文与已填写工作簿继续保留在 gitignored 路径；公开文件只包含标识符、标签、预测和输出哈希。

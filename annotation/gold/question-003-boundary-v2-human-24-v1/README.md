# question-003 boundary v2 人工盲审（24 条）

本目录冻结了 `question-003-boundary-v2-validation-v1` 中 24 条既有 L1 induced 输出的人工标签，并按[协议记录](../../preregistration/question-003-boundary-v2-human-24-v1.json)中事先写定的分析计划和决策规则，对冻结的 v1 与 v2 判定打分。

## 结论

**按决策规则采用 v2**：v2 组合管线在人工判为 engaged 的 23 条上零误报（规则上限 1 条），越界召回率 46.7%，高于 v1 的 0%。按较严标注者口径做的探索性敏感性分析得出相同结论。

但采用 v2 不等于 question-003 的越界已被充分检出：按主金标准，v2 仍漏掉 15 条人工越界中的 8 条（5 条判 clean、3 条 unresolved）。在 v2 下重新评分时，该题的越界数应视为下界。

## 人工标签

| 轴 | 结果 | 仲裁前一致性 |
|---|---|---|
| refusal | 23 engaged / 1 refusal | 24/24，κ=1.000 |
| boundary（仅 engaged） | 15 violation / 8 clean | 18/23，κ=0.582 |

5 条 boundary 分歧方向一致（标注者 01 判 violation、02 判 clean），第三位仲裁者在不知道前两者选择的情况下全部判 violation。因此最终 boundary 标签与标注者 01 的 23 条完全一致；两位标注者对 v2 判据的宽窄理解差异并未因仲裁消失。

## 打分（主金标准，23 条人工 engaged）

方括号内为精确 Clopper–Pearson 95% 区间。unresolved（包括判官分歧）降低 coverage，并在召回率中按漏检计。

| 预测 | coverage | 已解析准确率 | 越界召回率 | 越界精确率 | 误报 |
|---|---:|---:|---:|---:|---:|
| v1 组合 | 23/23 | 8/23 = 34.8% [16.4%, 57.3%] | 0/15 = 0% [0%, 21.8%] | —（无 violation 预测） | 0 |
| **v2 组合** | 20/23 = 87.0% | 15/20 = 75.0% [50.9%, 91.3%] | **7/15 = 46.7% [21.3%, 73.4%]** | 7/7 = 100% [59.0%, 100%] | **0** |
| v2 判官 A | 23/23 | 17/23 = 73.9% | 9/15 = 60.0% [32.3%, 83.7%] | 9/9 = 100% | 0 |
| v2 判官 C | 23/23 | 16/23 = 69.6% | 8/15 = 53.3% [26.6%, 78.7%] | 8/8 = 100% | 0 |

- v1 的 A、C 判官在这 23 条上都没有判出任何 violation。
- 配对比较：在 v1、v2 都已解析的 20 条中，只有 v2 判对的 7 条，只有 v1 判对的 0 条，精确 McNemar p=0.016。样本量很小，只作描述。
- refusal 门：冻结的 A/C 并集规则与人工 refusal 标签 24/24 一致。

## 敏感性分析（探索性，不在分析计划内）

以标注者 02 的仲裁前标签（较严口径：10 violation / 13 clean）为参照。由于所有分歧都是“01 判 violation、02 判 clean”且仲裁全部判 violation，这组标签可以从公开文件完整还原，`analyze.py` 不依赖私有文件。

|---|---:|---:|---:|
| v1 组合 | 0/10 = 0% [0%, 30.8%] | — | 0 |

决策规则在这一口径下同样得出“采用 v2”。判官 A 单独使用会有 2 条误报，A/C 一致才定案的组合规则把它们留成了 unresolved。

## 解读限制

- 只有一道题、24 条输出，不能估计 720 条总体率，也不能更新模型排行榜。
- 判官比人工主金标准读得更窄：v2 组合的 7 条 violation 全部正确，但漏掉了约一半人工越界。人工主金标准本身又跟随了较宽的那位标注者。
- 本批每一步都没有早于标签的公开时间戳，依据是本地文件时间和维护者声明；金标准在任何判官比较之前已公开冻结（提交 `0b3c516`）。
- v1 在这 23 条上漏掉了全部人工越界，说明历史 v1 结果中 question-003 的越界被严重低估。
